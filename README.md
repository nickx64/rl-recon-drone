# rl-recon-drone
Projekt drona poruszającego się po siatce w ramach fotografowania celów wykorzystujący uczenie ze wzmocnienie.


Agent wcielony w role drona musi wykonać kilka zdjęć i wrócić do bazy zanim padnie mu bateria. Każdy ruch zabiera mu baterię a na siatce znajdują się pułapki, powodujące koniec epizodu. Siatka zawiera również patrole poruszające się aktywnie po siatce. Kilka trudności map: łatwa, średnia, zaawansowana.
